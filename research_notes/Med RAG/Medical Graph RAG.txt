# Abstract
- Triple Graph Constructin and U-Retrieval to enchance GraphRAG

# 1. Method
-  begins with Triple Graph Construction, where documents are
chunked, and entities are extracted. Triple linking then connects user 
entities to referenced papers and vocabulary graph layers, forming the 
Med-MetaGraph. In the subsequent U-Retrieval phase, graphs are tagged 
to enable top-down precise retrieval and bottom-up response refinement,
ensuring graph-enhanced query responses.

## 1.1. Triple Graph Construction
### 1.1.1. Preliminary: Document Chunking & Entities Extraction
- Adopt the semantic chunking function implemented in LangChain.
- set a buffer size of 5 and enforce the token limit according to the 
graph construction LLM L^G.
- To extract entities, we prompt L^G to identify relevant entities in 
each chunk and generate a structured output wth name, type and a
description of the context. E = {e1, e2,...}, e = {na, ty, cx} (name 
is the text, type from UMLS and context generated by L^G.
